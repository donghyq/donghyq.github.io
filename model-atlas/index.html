第一次看？先弄清图里的 5 个词
Token（词元）：模型处理文本的单位。这里为方便讲解，把每个英文单词当作一个 token；真实分词可能把一个词拆成多个 token。
向量：表示一个 token 的一串数字。本例每个 token 用 4 个数字表示；维度本身通常没有可直接命名的语义。
矩阵：把多串数字按行排成表格。输入矩阵的一行是一个 token，列是它的特征维度。
权重参数：模型内部控制“数字如何变成另一组数字”的可训练数值。紫色矩阵表示这些参数。
注意力：为当前 token 分配“从哪些位置读取多少信息”的权重，然后按这个比例合并历史信息。
